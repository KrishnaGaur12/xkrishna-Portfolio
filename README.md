# Krishna Gaur Portfolio

Live: https://xkrishnagaur.netlify.app

## Stack
- React
- Tailwind CSS
- Vite
- React Router
- Framer Motion

## Run Locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Content Update
- Projects: `src/data/projectsData.js`
- Home sections: `src/components/Home Components/`
